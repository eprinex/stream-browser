# Stream Browser

Hızlı, Chaturbate odaklı canlı yayın tarayıcısı.

## Özellikler

- Chaturbate ana sayfada açılır
- Adres çubuğuna **oda adı** yazıp Enter → doğrudan odaya gider
- Sekmeler (Ctrl+T / Ctrl+W)
- Favori odalar
- Reklam / tracker engelleme (daha hızlı yükleme)
- Popup engelleme
- Her zaman üstte (çoklu görevde yayın izleme)
- GPU hızlandırma açık

## Kurulum

```bash
npm install
npm start
```

## Kısayollar

| Kısayol | İşlem |
|---------|--------|
| Ctrl+L | Adres çubuğu |
| Ctrl+T | Yeni sekme |
| Ctrl+W | Sekmeyi kapat |
| Ctrl+R / F5 | Yenile |
| Ctrl+Tab | Sonraki sekme |
| Ctrl+Shift+Tab | Önceki sekme |

## Not

18+ içerik. Yalnızca yasal, rızaya dayalı yetişkin içeriği izlemek içindir.
